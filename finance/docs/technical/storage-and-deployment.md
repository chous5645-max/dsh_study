# 技术设计：存储与部署

状态：候选方案；[SQLite 隔离实验](sqlite-persistence-verification.md)已验证部分合成事务与重试场景，尚未选择正式数据库库、文件路径、迁移及备份实现。业务需求是记录可追溯、可靠保存和可恢复，而不是必须采用某个数据库。

## 7. 持久化与部署提案

暂建议本地运行、SQLite 存储、原始文件单独保存并由数据库引用。实际路径、备份、迁移与 DSH 卸载行为需验证；删除聊天或禁用 UI 不得隐式删除账本。

本地存储不代表本地推理。发送模型的数据以必要字段与汇总为主，避免自动提交完整原始账单。密钥不进入账本和日志；原始金融文件不提交到代码仓库。

两个插件可放在同一仓库协调版本。固定 DSH 验证版本，保留升级检查。尚未选定打包方式、UI 入口、图表库及具体 DSH 注册接口。
