# 技术总体设计：双插件架构

状态：从早期混合草案整理而来。双 DSH 插件与复用 Agent 为既定方向；固定版本的 Host 装配、浏览器客户端、运行期 Gateway Remote 与合成数据重启恢复已做烟测；合成严格 Remote 契约已在 Node Client Remote 中调用，正式外部包与浏览器调用仍未验证；财务业务对象和账本存储尚未实现。需求依据见 [overview.md](../requirements/overview.md)。本文不代替需求确认，也不划分开发优先级。

## 2. 两个插件与 Agent

### finance-core Module

拥有账务规则、数据持久化和统一 Interface：账户管理、交易修改、账单解析、导入任务、去重关联、分类规则、统计与报表数据、变更追踪。

对 DSH Agent 暴露受约束的财务工具，对 UI 暴露业务 Interface。两种调用入口共享同一实现；工具应围绕任务组织，避免为每张表暴露一组 CRUD 工具。

解析器属于内部 Adapter；在不同账单来源的格式处设置 Seam。金额、汇总、入账校验由确定性代码完成。DSH 适配代码与账务计算分离，但先不建设通用框架。

### finance-ui Module

依赖核心，拥有导入中心、账户、交易明细、待核对列表、统计图表和报表呈现。负责筛选、预览、批量操作与分析入口。

统计数值从核心获取；图表、排版和用户交互由 UI 负责。普通界面查询不经过模型。点击分析时传入账本、筛选条件和统计口径，由 Agent 按需查询。

### DSH Agent

复用 DSH 现有会话与模型能力，不单独建设第三个分析插件。负责意图理解、模糊分类建议、多步查询和结论解释。可附带财务使用说明或 Skill，但不能依靠提示词保证账务规则。

Agent 通过工具读取与修改账目；不将任意 SQL 或文件写入作为产品的正式业务路径。数据中的商户文字和备注是输入数据，不是 Agent 指令。产品配置需约束通用工具绕过财务 Interface 的可能性。

## 6. 候选 Interface（非 DSH 已有接口）

| 任务 | 输入示意 | 输出与约束 |
| --- | --- | --- |
| 创建导入 | 账本、文件引用、来源选项、幂等标识 | 持久化任务标识 |
| 查看导入 | 任务标识 | 进度、解析摘要、核对项、预览版本 |
| 提交导入 | 任务标识、已处理核对项、预览版本 | 提交结果；重复调用不重复入账 |
| 查询交易 | 账本、筛选、分页 | 明细、来源引用、修订号 |
| 汇总分析 | 账本、范围、维度、口径 | 确定性数值、覆盖范围、明细引用 |
| 预览与应用更正 | 交易标识、改动内容、预期版本 | 差异预览或已应用结果；版本冲突可解释 |
| 管理账户与规则 | 明确的业务动作与数据 | 校验结果、变更记录 |

本表为早期能力清单，后续操作契约以 [核心业务 Interface](core-interface.md) 提案为准。这些是能力分组，不是冻结的方法名或最终工具数量。错误应区分格式不支持、字段缺失、账户未知、版本冲突、数据不完整和运行失败；不能让调用者猜测字符串含义。

## 9. 预算与计划扩展提案

详细方案见 [预算、周期计划与未来现金流](../requirements/budgets-and-planning.md)。核心 Module 管理预算版本、周期规则、计划实例与执行分配；UI 展示预算、日历和预测；Agent 提出规则与解释场景。计划不自动形成实际账目，预测在当前可信余额上仅叠加未来未执行金额。调度及应用关闭后的恢复尚未验证。

## 10. 其他资产扩展提案

详见 [押金、预付、储值与其他资产](../requirements/assets-and-prepayments.md)。押金复用往来结算；预付与储值区分未消耗成本和商户额度；投资分开现金、持仓、成本与估值。付款不自动等同消费，资产估值不等同可用资金；具体计量方式需在范围完成后统一进核心模型。

## 11. 账本与共享提案

详见 [账本、视图与家庭共享](../requirements/books-and-sharing.md)。建议个人账本内使用账户、标签、事项和保存视图；独立账本用于独立数据维护。家庭共享已明确后续迭代；独立账本能力保留，日常以一个账本组织。核心操作需明确账本归属，不能默认同名账户或共享视图提供完整数据隔离。

## 12. 分类、标签与事项提案

详见 [分类、标签、事项与视图](../requirements/categories-tags-and-events.md)。业务类型决定账务处理，主分类表达性质，标签用于交叉筛选，事项用于活动归组。标签与事项不替代退款、报销或借贷结算关系；重叠视图不重复计入总额。
