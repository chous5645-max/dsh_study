## 3. 数据关系提案

账户与往来方向已确认，详细关系见 [账户、负债与往来结算](../requirements/accounts-and-settlements.md)。往来明细解释账户或应收应付余额的组成，不重复计入资产负债；业务规则与具体实现仍需验证。

- 账本：长期业务数据容器，独立于 DSH 会话；日常一个个人账本，允许独立数据账本，家庭共享后续迭代。
- 资金账户：现金、银行卡、零钱及支付余额，记录持有的资金。
- 负债账户：信用卡、贷款等，记录现有负债；额度与未来计划不视为当前余额。
- 往来对象与明细：个人或组织的借入、借出、垫付及报销，记录产生依据和未结金额。
- 结算分配：收付款与往来明细的金额对应，支持部分结算及多笔合并结算。
- 报销记录与还款计划：分别跟踪业务进度和预期变动，与实际收付款区分。
- 支付渠道：微信、支付宝等；不等同于实际扣款账户。
- 导入批次：文件来源、内容摘要、解析器版本、任务状态和统计结果。
- 来源记录：原文件中的记录，保存行位置或页位置与解析结果；保留来源，不直接全部当成消费。
- 记账记录（交易）：消费、收入、转账、退款或还款的账本表达，可关联多条来源记录；无需预先识别完整活动事项。
- 账户变动：交易对资金账户的影响；用于表达转账双方，是否实现完整复式分录仍待决定。
- 分类与规则：用户可编辑的消费分类，以及明确确认的匹配规则。
- 核对项：疑似重复、账户未知、退款未关联等问题及其处理结果。
- 变更记录：修改前后、发起入口、时间与撤销或更正关系。

金额使用最小货币单位整数或精确十进制，禁止浮点金额计算。日期保留来源精度；仅有日期时不能编造精确时间。币种明确记录并校验一致；多币种处理暂缓，详见 [books-and-sharing.md](../requirements/books-and-sharing.md)。

余额必须有可信期初、余额快照或足够完整流水作为依据。流水不全时显示数据范围，不推断完整净资产。

## 往来关系候选（从需求草案迁入）

## 2. 统一关系

记账记录 → 账户变动。
记账记录 → 可选的应收/应付明细 → 结算分配 → 后续收付款记录。
记账记录 → 可选事项归组。

这里的“往来事项”是产生债权债务的业务明细；“事项归组”只是用户可选的活动组织方式。新增往来并不要求创建一个聚餐或出差归组。

应收明细候选字段：对象、类型、产生依据、币种、确认金额、已结金额、调整金额、未结金额、约定日期及证据。
应付明细使用对称结构。预计日期与约定到期日应区分；没有日期时不自动判定逾期。

结算分配记录收付款与往来明细之间的金额关系。一个付款可结算多项欠款，一项欠款可分多次结算。一笔流水被导入多次或被多个渠道描述，不增加新的结算事实。

## 多账本请求与隔离候选

## 7. 多账本 Interface 与数据归属提案

核心读写操作显式携带账本标识；UI 可使用当前账本作为默认值，但每次请求提交固定账本，不能依赖异步执行时变化的全局选择。Agent 工具也明确目标账本，歧义写入不猜测。

账户、交易、预算、规则、导入任务和核对项均有账本归属。同账本约束在核心校验，不能只靠 UI 筛选。跨账本迁移必须预览来源、关联、结算与余额影响，不能仅修改一列标识。

来源文件可能包含多个用途或成员数据，不能因单条记录被分享就暴露整个文件。后续若有共享，明细、附件、导出、搜索、汇总和 Agent 查询均需同一访问控制。

单用户可对自己账本提示跨账本重复来源；不同用户之间不能通过重复提示泄露其他账本的存在或交易。内容摘要去重与用户可见授权需分开。

账本归档停止新写入但保留查询；删除、迁移、跨账本合并的完整规则以后单独设计，当前不承诺。

## 币种扩展位置

## 8. 多币种暂缓与扩展位置（已确认方向）

本阶段按单币种设计，不实现换汇、汇率接入、汇兑损益或跨币种净资产合并。单币种具体默认值可配置，示例继续使用人民币；不把用户暂缓多币种理解为必须永远硬编码人民币。

金额在领域层携带币种；账本声明核算币种，写入与查询进行币种一致性校验。采用最小货币单位整数或精确十进制，不能把所有币种永久假定为两位小数。金额解析和格式化集中封装。

若导入意外出现外币，保留来源原文并标记当前不支持，不能按人民币静默入账或直接相加；无需现在实现一整套换算模型。

未来可在来源原币金额、核算金额、汇率值/日期/来源等位置扩展；当前只保留币种语义和版本迁移能力，不提前创建空的汇率系统。若来源提供已结算人民币金额，可以按明确人民币结算事实记账，原币信息作为来源证据保留，避免重复计数。

## 分类、标签与事项的技术约定

分类、标签、事项通过稳定标识关联，改名不修改身份；名称不是关系主键。拆分分配与弱关联需分别表达，候选关系与已确认关系分开。界面筛选对应明确查询条件，不能隐含重复计数。具体字段、索引、约束与版本机制待设计。
